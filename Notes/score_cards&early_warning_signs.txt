/////////////SCORE CARDS//////////////////

Once you get the PD of each customer, you can use score cards to classify them in ratings

# Example: After training your logistic regression or XGBoost model
# You get predicted PDs
import numpy as np
import pandas as pd

predicted_pds = np.array([0.01, 0.05, 0.10, 0.35, 0.60, 0.85])  # example

# Convert PDs into decile-based scorecard (score 1–10)
scorecard = pd.qcut(predicted_pds, 10, labels=False) + 1  # Score from 1 (best) to 10 (worst)

# You now have:
# - predicted_pds = [0.01, ..., 0.85]
# - scorecard = [1, 2, 3, ..., 10]

You can later attach expected PD ranges to each score bucket:
# Scorecard mapping example:
score_to_pd = {
    1: 0.01,   # 1% PD
    2: 0.02,
    3: 0.05,
    ...
    10: 0.30   # 30% PD
}

/////////////EARLY WARNING SIGNS//////////////////

Examples of Early Warning Signals:

| Category               | Variable                                |
| ---------------------- | --------------------------------------- |
| **Credit Usage**       | % of credit line used                   |
| **Repayment Behavior** | Days past due, partial payments         |
| **Behavioral Changes** | Increased spending, sudden income drop  |
| **Macroeconomic**      | Rising unemployment, inflation          |
| **Transactional Data** | Cash withdrawals increase, low deposits |
| **Customer Status**    | Repeated contact changes, complaints    |

How to simulate them in the game?

1. Add a credit_status variable per period: "OK", "warning", "at risk", "default".Update it based on rules (or a small model) using behavior since last period.

2. Design simple rules (or a Probailistic EWS Model)

def early_warning(customer):
    score = 0
    if customer["credit_usage_ratio"] > 0.9:
        score += 2
    if customer["income_drop_pct"] > 0.3:
        score += 2
    if customer["repayment_days_late"] > 15:
        score += 3
    if customer["economic_shock"] == True:
        score += 1
    
    if score >= 5:
        return "at risk"
    elif score >= 3:
        return "warning"
    else:
        return "OK"

3. Introduce a Feed back loop 
- If a customer is flagged "warning" or "at risk":
    You can reduce available credit, increase rates, or ask for collateral.
